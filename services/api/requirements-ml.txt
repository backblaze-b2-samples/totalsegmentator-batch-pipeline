# Optional imaging / ML extension — the segmentation and volumetric-stats
# features only.
#
# NOT part of the core install: `pnpm run setup` and CI install requirements.lock,
# and `pnpm verify` runs against a venv WITHOUT this file. Nothing here is
# imported at app boot either — repo/segmentation.py and repo/nifti_stats.py
# import torch / TotalSegmentator / nibabel / NumPy lazily, inside functions. So
# the core suite stays light and green, and a run on a clone without this stack
# records the study as `failed` with an actionable message (never a 500).
#
# Install it on a CUDA or CPU host to run real segmentation:
#     services/api/.venv/bin/pip install -r services/api/requirements-ml.txt
# For CUDA, install the matching torch build from https://pytorch.org first; the
# default index resolves the CPU wheel, which also works (slower).
#
# TotalSegmentator wraps nnU-Net v2 / PyTorch and downloads its own model
# weights on first use (Apache-2.0; no gated Hugging Face token required).
#
# setuptools>=81 removed pkg_resources, but TotalSegmentator 2.5.x still does
# `import pkg_resources` at engine import time, so a fresh install without
# this pin fails with `ModuleNotFoundError: No module named 'pkg_resources'`
# the first time segmentation runs. Pin below 81 until upstream drops it.
setuptools<81
TotalSegmentator>=2.4.0,<2.6
nnunetv2>=2.4.1,<3
torch>=2.2.0,<2.8
nibabel>=5.2.0,<6
numpy>=1.26.0,<2.2
SimpleITK>=2.3.0
